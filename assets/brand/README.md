# Rayhanson website identity

Selected original exports from Harvey’s supplied Rayhanson logo kit. The uploaded archive remains the master source; these website copies retain the original artwork and aspect ratios.

| File | Placement |
| --- | --- |
| `rayhanson-horizontal-reflective-dark.png` | Homepage identity at a readable size |
| `rayhanson-symbol-ivory.svg` | Compact navigation rail |
| `rayhanson-wordmark-ivory.svg` | Expanded rail and mobile header |
| `rayhanson-horizontal-ivory.svg` | Footer |
| `favicon.ico` | Browser fallback, supplied multi-size icon |
| `rayhanson-icon-180.png` | Apple home-screen icon |
| `rayhanson-icon-192.png`, `rayhanson-icon-512.png` | Web manifest icons |
| `palette.json` | Original brand colors |

`../favicon.svg` is the original supplied vector app icon. `../portfolio-banner.svg` and `../portfolio-share.svg` arrange the supplied ivory vectors with portfolio copy; the artwork paths are not redrawn or filtered. `../portfolio-share.png` is the social-card export.

The reflective PNG is displayed without recoloring, distortion, or CSS filters. Ivory vectors keep the small placements readable. `../../brand.css` applies the site palette: navy `#0A0F14`, deep teal `#0F3D3E`, muted teal `#2E6F73`, light teal `#7FB3B8`, cream `#EADCC8`, and burnt orange `#C6601F`. The original logo palette is recorded separately in `palette.json`.
