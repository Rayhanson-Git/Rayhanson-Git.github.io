The project

Not mine
Glad to help

Tesseract is an open-source project by Taimoor. It gives AI agents a persistent, shared memory kept in a plain-Markdown Obsidian vault.

Its server offers hybrid search, a knowledge graph you can browse, and a caretaker that maintains the vault. The design and the project are his. This page covers the one change I contributed.

Read about Tesseract in its repository (opens in a new tab)

The problem

Shared memory
One writer at a time

Tesseract is meant to be shared by several agents, but its write path assumed one writer. A create-only write checked that a note did not exist and then replaced the file. Two agents logging the same session title at the same moment could both pass the check, and the second silently overwrote the first.

Every note was also signed with the same agent name, so a vault written by several agents could not tell them apart.

The change

One winner
Every note signed

Figures from the pull request.

Create-only writes
A new note is published in one atomic step, so exactly one concurrent writer wins and the other is told the note exists.
Session logs
A second log with the same title is saved under the next free name, so both are kept.
Concepts
An agent that loses the race extends the concept another agent just created.
Identity
Each server instance takes its own agent name, recorded in every note it writes.

18 files changed: 791 lines added, 189 removed.
Tests
7 new tests, including a 16-way race with exactly one winner. Full suite: 619 passed, 3 skipped.
